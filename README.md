**Executive Summary**

The Gaming Room sought to expand the reach of their popular Android game, "Draw It or Lose It," by transforming it into a web-based application accessible across different platforms. This strategic move aimed to broaden the game's player base and inclusivity, enabling team-based puzzle-solving challenges based on pre-made drawings.
